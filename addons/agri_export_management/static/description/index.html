Agricultural Export Management

Farm to Shipment — Complete Export Operations for Odoo 19

What does it do?

A complete vertical solution for agricultural exporters, packhouses, and fresh produce trading companies. Covers every step from farm evaluation through production, cold storage, container booking, lot-level reservation, logistics costing, and customer delivery — with full lot-to-farm traceability and season-level P&L.

The Workflow

1. Farm Evaluation

  • Pre-purchase yield assessment per Grade × Size
  • Expected vs Actual with Achievement %
  • One-click Purchase Order creation
  • Intercompany SO linking (multi-company)

2. Production Batch

  • Raw material → finished goods stock moves
  • Scrap/waste recording (5 types)
  • Packaging material costs
  • Absorption costing with actual/manual modes
  • Optional MRP Manufacturing Order mode

3. Export Shipment

  • Container management + seal numbers
  • Lot reservation (FIFO, grade/size filtered)
  • Lot → Carton → Pallet hierarchy
  • Logistics cost allocation (5 bases)
  • Automated SO and Delivery generation

Standard Odoo Integration

No duplicate master data — uses standard Odoo models where possible:

  • Farms: res.partner with "Is Agricultural Farm" flag
  • Crops: product.category with "Is Agricultural Crop" flag
  • Destination: res.country + port field
  • QC Inspections: Odoo Quality module (optional)
